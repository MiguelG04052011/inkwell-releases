# Inkwell social media files

This branch holds the files Inkwell's short videos are made and published from (TikTok, Instagram and YouTube):
`videos/` has the finished videos the scheduled posts point at, and `studio/` has the screens, fonts and the code
that turns them into videos. It is not part of the app. The app's releases and downloads are on the main branch and
the Releases page, as before.

Videos older than about a week are removed once their posts have gone out.
